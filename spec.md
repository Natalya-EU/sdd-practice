# Feature: Линеечка похудения (Weight Tracker) — v2

## Context
Одностраничное веб-приложение для визуализации прогресса похудения.
Открывается в браузере двойным кликом, без сервера и установки программ.
Один HTML-файл со встроенными стилями и скриптом.

## Requirements
- Три поля ввода: Начальный вес, Текущий вес, Цель
- При ПЕРВОМ открытии все поля пустые — пользователь вводит свои значения
- Поддержка десятичных дробей (например, 70.5)
- Нечисловые символы (буквы) при вводе молча игнорируются, без подсказок
- Горизонтальная полоса-линейка с бегунком, показывающая прогресс
- Текстовая подпись под линейкой: «Вы скинули X кг, осталось Y кг»
- Пересчёт мгновенно при вводе чисел (без кнопки «Обновить»)
- Значения автоматически сохраняются в localStorage браузера
  и восстанавливаются при следующем открытии страницы
- Если введённый текущий вес БОЛЬШЕ стартового — стартовый вес
  автоматически заменяется текущим (поле «Старт» обновляется сам)

## Design
- Стиль: минимализм, много воздуха
- Цвета:
  - Фон страницы: градиент из тёмно-синего (#000c22) в синий (#1856c8)
  - Весь текст: белый (#FFFFFF)
  - Бегунок и заполненная часть линейки: салатовый (#5deb28)
  - Незаполненная часть линейки: полупрозрачный белый (белый 20%)
  - Поля ввода: полупрозрачные, белый текст, салатовая рамка при вводе
- Шрифт: системный sans-serif

## Logic (формулы)
- Пройдено (%) = (Старт − Текущий) / (Старт − Цель) × 100
- Скинуто (кг) = Старт − Текущий
- Осталось (кг) = Текущий − Цель
- Позиция бегунка = Пройдено %, но не меньше 0 и не больше 100
- Сохранение: при каждом изменении полей значения пишутся в localStorage
- Загрузка: при открытии страницы значения читаются из localStorage
- Автозамена старта: если Текущий > Старт, то Старт := Текущий.
  Обновлённое значение сохраняется в localStorage вместе с остальными.

## Edge Cases
| Ситуация | Поведение |
|----------|-----------|
| Первое открытие, полей нет в localStorage | Все поля пустые, бегунок в начале, подписи нет |
| Заполнены не все три поля | Бегунок не двигается, подписи нет (ждать полных данных) |
| Ввёл буквы | Символы молча игнорируются, в поле остаются только цифры |
| Текущий вес БОЛЬШЕ стартового | Старт автоматически заменяется текущим весом; бегунок в начале (0%), подпись: «Вы скинули 0 кг, осталось (Текущий − Цель) кг» |
| Текущий вес МЕНЬШЕ цели | Бегунок на 100%, «🎉 Цель достигнута!» |
| Цель больше старта (опечатка) | Бегунок не двигается, подписи нет |

## Acceptance Criteria
- [ ] Файл index.html открывается двойным кликом в браузере
- [ ] При первом открытии поля пустые, пользователь вводит старт/цель/текущий вес
- [ ] Бегунок и подписи пересчитываются мгновенно при вводе
- [ ] Буквы в полях не попадают, подсказок нет
- [ ] После обновления страницы введённые значения остаются на месте
- [ ] Все краевые случаи работают как описано
- [ ] Цвета соответствуют дизайн-блоку (градиент #000c22 → #1856c8, акцент #5deb28, текст белый)
- [ ] При вводе текущего веса больше стартового поле «Старт» обновляется автоматически
