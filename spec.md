# Feature: Линеечка похудения (Weight Tracker)

## Context
Одностраничное веб-приложение для визуализации прогресса похудения.
Открывается в браузере двойным кликом, без сервера и установки программ.
Один HTML-файл со встроенными стилями и скриптом.

## Requirements
- Три поля ввода: Начальный вес, Текущий вес, Цель
- Значения по умолчанию: старт = 126.1, цель = 65
- Поддержка десятичных дробей (например, 70.5)
- Горизонтальная полоса-линейка с бегунком, показывающая прогресс
- Текстовая подпись под линейкой:
  «Вы скинули X кг, осталось Y кг»
- Пересчёт мгновенно при вводе чисел (без кнопки «Обновить»)

## UI Structure
┌─────────────────────────────────────┐

│                                     │

│  Цель:  [65.0]                      │
│                                     │
│  ■■■■■■■■■■░░░░░░░░░░░░░░░░░░░░░░   │ ← линейка с бегунком
│  ●── бегунок (текущая позиция)      │
│                                     │
│  Вы скинули 10.3 кг,                │
│  осталось 50.8 кг 💪                │
└─────────────────────────────────────┘

## Design
- Стиль: минимализм, много воздуха, без лишних деталей
- Цвета:
  - Фон: белый или очень светло-серый (#F5F6FA)
  - Основной (заголовки, текст): тёмно-синий (#1E2A4A)
  - Акцент (бегунок, заполненная часть линейки): салатовый (#A8E063)
  - Незаполненная часть линейки: светло-серый (#E4E7EF)
- Шрифт: системный sans-serif (как в macOS/Windows)

## Logic (формулы)
- Пройдено (%) = (Старт − Текущий) / (Старт − Цель) × 100
- Скинуто (кг) = Старт − Текущий
- Осталось (кг) = Текущий − Цель
- Позиция бегунка = Пройдено %, но не меньше 0 и не больше 100

## Edge Cases
| Ситуация | Поведение |
|----------|-----------|
| Текущий вес пустой или не заполнен | Линейка на 0%, подпись: «Введите текущий вес» |
| Ввёл буквы вместо цифр | Игнорируем, показываем подсказку «Только числа» |
| Текущий вес БОЛЬШЕ стартового | Бегунок в начале (0%), подписи: «Скинули 0 кг» |
| Текущий вес МЕНЬШЕ цели | Бегунок на 100%, подпись: «🎉 Цель достигнута!» |
| Цель больше старта (опечатка) | Показываем предупреждение «Проверьте значения» |

## Acceptance Criteria
- [ ] Файл index.html открывается двойным кликом в браузере
- [ ] При загрузке страницы линейка показывает прогресс от 126.1 до 65
- [ ] При вводе текущего веса бегунок сразу перемещается
- [ ] Подписи «скинули / осталось» пересчитываются корректно
- [ ] Все 5 краевых случаев работают как описано
- [ ] Цвета соответствуют дизайн-блоку
